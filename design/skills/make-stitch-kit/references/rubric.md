# Rubric — Stitch DESIGN.md

Scores one Google Stitch DESIGN.md (authored, evaluated, or regenerated by this skill). `[gate]` = mechanically checkable — the "How checked" column names the checker; `[review]` = judgment with cited evidence on the 1–5 anchors. Anchored to spec version **alpha** (fetched 2026-07-05); re-anchor on upstream version bump.

| # | Dimension | Type | How checked | 1 (fail) → 3 (adequate) → 5 (excellent) |
|---|---|---|---|---|
| G1 | Lint clean | [gate] | `npx -y @google/design.md lint` → `summary.errors` | 1: any error (`broken-ref`, rejected file) · 3: zero errors, warnings unread · 5: zero errors AND every warning classified per `lint-gate.md` §3 |
| G2 | Section grammar | [gate] | `scripts/prelint.py check` (order, duplicates) | 1: duplicate heading or canonical names out of order · 3: canonical subset ordered · 5: all 8 canonical names verbatim, appended sections after Do's and Don'ts |
| G3 | References resolve | [gate] | prelint + lint `broken-ref` | 1: any dangling `{path.to.token}` · 3: frontmatter refs resolve · 5: frontmatter AND prose refs resolve; components reference roles, never repeat raw values |
| G4 | Scheme parity | [gate] | prelint parity check | 1: roles present in one scheme only · 3: parity holds · 5: parity holds and the file states the pick-the-pair instruction |
| G5 | Required roles & on-pairs | [gate] | prelint (`primary`, base components carry `textColor`) + author sweep | 1: no `primary`, or fills without on-partners · 3: `primary` alias present, component pairs complete · 5: every fill role carries the KIT's on-partner per scheme (constant on-colors under `onColorMode: fixed` are the kit's design — called out as DIVERGENCE, never silently re-pointed; kit fidelity, PR #229) |
| G7 | Relative leading/tracking | [gate] | prelint px-unit check on `typography.*` | 1: any `lineHeight`/`letterSpacing` in px · 3: all values unitless/em/% · 5: 3 plus the Typography prose states the rule (factor `1.5`, `0.06em`, or `%` — never px) |
| G6 | Contrast, both schemes | [gate] | lint (light-end component pairs) + [[check-colors]] all-pairs proof | 1: any UNDISCLOSED declared pair < 4.5:1 · 3: light-end component pairs pass or every miss disclosed (`onColorMode: fixed`, ADR-003 — classify with the receipt: `prelint.py classify <lint.json> <README.md>`) · 5: ALL fill/on pairs ≥ 4.5:1 in both schemes, proof cited in the receipt |
| R1 | Specific reference | [review] | Overview reading | 1: adjective list ("modern, clean, premium") · 3: a reference plus stray adjectives · 5: one named world whose physics the rest of the file visibly derives from |
| R2 | Prose–token accord | [review] | cross-read prose ↔ frontmatter | 1: prose sells colors/effects no token delivers, or tokens no prose explains · 3: accord holds for major roles · 5: two-way accord — every role has a boundary and a refusal in prose; every prose promise is a token |
| R3 | Negative constraints | [review] | Do's and Don'ts reading | 1: absent or generic ("keep it clean") · 3: present, some load-bearing · 5: short, deliberate refusals a generic generation would violate; hard rules ranked first |
| R4 | States as values | [review] | Components section + frontmatter variants | 1: states as adjectives ("hover brightens slightly") · 3: hover/active variant keys shipped · 5: hover/active/focus/disabled all concrete — variant tokens plus focus ring geometry stated |
| R5 | Role budget & naming | [review] | count roles; check names against the slot registry | 1: full ramps shipped, or invented names · 3: 15–25 roles, mostly grammar-conforming · 5: 15–25 constructed `{family}-{slot}` names, grammar taught in-file, divergences from an upstream system called out |

**Gate to ship:** G1–G7 all ≥ 3, with G1 and G6 at 5 for a delivered export (a shipped file has its warnings classified and its dark scheme proven). Review dimensions < 3 block only when R2 fails — a story the tokens cannot deliver forces hardcoding, which breaks the token contract.

**Top failures to look for first:** (1) constant on-colors — lint passes the light end while the dark scheme silently fails AA (G5/G6); (2) a lint-clean file whose Overview is an adjective region, not a point (R1) — structurally perfect, generatively generic.
