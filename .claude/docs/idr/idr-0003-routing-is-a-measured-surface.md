# IDR-0003 — Routing quality is a measurable property of names and descriptions

## Claim

Governing names and description text as a routing surface — blind-judge eval suites, reciprocal
fences between siblings, a ratified naming grammar — measurably reduces stolen, leaked, and dead
routes in `/check-routing` matrices. Sustained no-signal in post-vote matrices across governed
description edits falsifies; `hung` cases are excluded as measured case ambiguity, not counted
either way.

## Why

Provenance: derived-from-evidence — `.claude/rules/plugin-authoring.md` ("Descriptions are the
routing surface", evals updated in the same change), `/check-routing`'s stolen/leaked/dead/hung
tuning matrix, and three ratified naming investments: one funded estate-wide rename campaign
(ADR-0006), a follow-on ratified rename (ADR-0009), and an adopted naming grammar (ADR-0011,
amended by ADR-0014). The estate has repeatedly ratified naming investments on this belief; the
belief itself has no record.

## Proof

`/check-routing` matrix results across description-boundary edits: an edit made under this
discipline measurably improving its plugin's post-vote matrix confirms; sustained no-signal
despite governed edits falsifies.
