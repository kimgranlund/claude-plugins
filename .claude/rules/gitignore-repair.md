# .gitignore repair on path retirement

**Path scope:** `.gitignore`, and any change deleting or renaming a path that a `.gitignore`
rule names (the governed act, not just edits to the file itself).

A change that retires a path a `.gitignore` rule names repairs the rule in the same change —
rulings + history: ADR-0002, the git-native memory, harness's clean-repo razor.
