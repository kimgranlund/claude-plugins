# Rubric — Agent-Corpus Audit (cross-cutting)

Scores a whole `agents/` team on the four cross-cutting properties **no single-agent review can see**: a naming *grammar*, language *potency*, front-matter *as an interface*, and the agent→skill *leverage graph*. Two dimensions are owned here (N, S — genuinely corpus-level); L delegates entirely to the per-agent standard that owns it (``prompt-wording-rules``); F's per-agent leg delegates to ``agent-writing-rules``, but its pairwise differentiation leg is corpus-level and mechanized here (`agent_corpus_index.py`'s F-section). Scoring method (1–5, `[gate]`/`[review]`, gate threshold) is summarized at the bottom.

| # | Dimension | Plane | Type | What it checks | 1 → 3 → 5 |
|---|---|---|---|---|---|
| N | Naming-convention strategy | corpus | [gate] uniqueness + no non-agent · [review] grammar | `agent_corpus_index.py`: names unique (the namespace is flat *per scope*: a duplicate within a scope is silently dropped, and a repo-local `.claude/agents` name **shadows** the same-named user-scope agent — check both scopes) and every file a real agent (gate); `<domain-noun>-<role>` grammar — role is a stable function noun, domain a memorable noun **decoupled from the skill's name** (`wiring-checker`, never `orchestration-design-reviewer`); one grammar per team; every role collision either domain-disambiguated or merged; no redundant `-agent` suffix | 1: a duplicate name / a non-agent file in the dir / two grammars whose overlapping roles are duplicate agents · 3: unique, one grammar dominates, collisions defensible · 5: single grammar, every role domain-disambiguated or merged, zero non-agent files, names memorable and decoupled from skill names |
| L | Linguistic-technique alignment | per-agent → rolled up | [review] (per-agent gate = ``prompt-wording-rules`` L1/L3/L6) | every agent body *instantiates* its judgment-frame rather than *describing* it, and holds the potency lint budget | 1: bodies describe the role · 3: mixed across the set · 5: every load-bearing line in every agent instantiates, all within budget — scored via `wording-checker` |
| F | Front-matter strategy | per-agent + pairwise | [gate] harness agent (D1·D2·D5·D7) · [review] differentiation | each agent: `description` = capability + a model-evaluable auto-delegation trigger; `tools` scoped to the role's blast radius **and sufficient for it** — tool insufficiency is as much a finding as tool excess; `model` to task class; invariants in hooks not prose (D7); **differentiated from every peer** so routing is unambiguous — the pairwise leg is mechanized: `agent_corpus_index.py`'s F-section tests each agent's own quoted trigger phrases against every sibling's description via `routing_eval`'s lexical-overlap proxy (a hit with no fence naming the phrase's owner is a candidate collision, filtered to phrases with ≥3 content tokens so corpus-universal words like "review"/"agent" don't flood the report); still [review] — the proxy is lexical-overlap only, so the scorer judges real ambiguity vs. shared-vocabulary noise | 1: an over-broad/omitted `tools` / a seat whose tools cannot perform its role (a coordinator without `Task` cannot dispatch) / a vague or peer-overlapping description / enforcement-in-prose · 3: each precise and scoped · 5: each precise **and** differentiated from all peers (no unresolved F-section collision) + tools minimal-but-sufficient — scored via ``agent-writing-rules`` D1/D2/D5/D7 + the Phase-0 F-section |
| S | Global-skill leverage (1+1=3) | corpus graph | [gate] no dangling preload · [review] completeness | `agent_corpus_index.py` graph: every `skills:` preload resolves (gate); every agent whose role carries *standing* expertise preloads the matching skill — a coordinator wires the orchestration skills, a reviewer preloads its standard, a maker its authoring skill — so agent + skill = 1+1=3; the **universal-preload idiom**: when the team standardizes a preload (12/13 agents preload `write-handoff`), the member missing it is a finding, not a style choice | 1: agents that should compose with a skill preload nothing (a coordinator with no orchestration skill, a reviewer with no standard) · 3: the leads are wired, the newer seats aren't — or a universal-preload outlier remains · 5: every role's standing expertise is preloaded, reciprocal to the maker skills, zero dangling, no universal-preload outlier — related to ``fleet-rules`` D3 |

**Gate to promote (the team is production-ready when):** N — names unique **and** no non-agent files; F — every agent clears the harness agent gate (D1/D2/D5/D7); L — every agent body clears L1/L3/L6; S — no dangling `skills:` preload. The `[review]` tiers (grammar coherence, per-peer differentiation, leverage completeness) are the excellence axes above the floor.

**Top failures to look for first:** a universal-preload outlier (S) — the team standardized a preload and one member is missing it (12/13 agents preload `write-handoff`; the odd one out is the finding); a seat whose tools cannot perform its role (F) — a coordinator without `Task` cannot dispatch; and cross-scope shadowing (N) — a repo-local `.claude/agents` agent silently shadowing its same-named user-scope twin. Historical note: the pre-audit estate's top failure was a naming-grammar split hiding **duplicate agents** (N) — a `*-lead` team and an `adia-ui-*` team both coordinating/planning/building/reviewing; that estate is extinct, but a two-scheme corpus still gets this check first.

---

**Scoring method.** `[gate]` = mechanically checkable (the index's violation exit, the harness agent gate); score by the script. `[review]` = judgment; score against the anchors with cited evidence (`agent:line`, the offending name or preload). Scale 1–5 (1 = failure anchor, 3 = adequate, 5 = excellence anchor); do not round everything to 3. A team that trips any gate tier is not production-ready regardless of the `[review]` scores.
