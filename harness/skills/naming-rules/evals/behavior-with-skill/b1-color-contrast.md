# b1 — name for a WCAG color-contrast checking skill

**Proposed name:** `check-contrast`

**Reasoning:** A procedural skill is a runnable, so the shape is verb-first `verb-noun` (kind-audible), and "judge against a bar" maps to the registry verb `check` — never `verify`, `audit`, or `validate`, all retired synonyms. It completes "I want to check contrast" in kindergarten vocabulary with no lore; WCAG is the bar it checks against, which belongs in the description, not the name.
