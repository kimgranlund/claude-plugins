# b3 — name a doc-writing knowledge skill (with skill)

**Name:** `doc-writing-rules`

**Reasoning:** A binding knowledge skill (rules to follow, not facts) takes the shape
noun + activity + `-rules` (Shapes table), and the `-rules` refinement requires the activity
word — `doc-writing-rules`, never `doc-rules` — since a bare `doc-rules` would claim all rule
families about docs. Passes all five tests: no verb needed (not runnable), kind audible from
the `-rules` suffix, no lore, kindergarten words.
