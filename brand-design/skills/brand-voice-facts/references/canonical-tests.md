# Canonical tests — the concrete diagnostics this family runs

Each test is [verified] as a specific, repeatable prompt drawn from a persona file
(`check-brand-council/references/critics/`, dated 2026-08-20).

1. **The wife test** (David A.) — read the headline as if the reader were a specific real
   person you respect; rewrite anything you wouldn't say to her face [verified].
2. **The adjective-underline test** (David A.) — underline every adjective and demand the fact
   it stands in for; where no fact exists, cut it [verified].
3. **The legally-true test** (David A.) — ask if a claim is actually true, not merely legally
   defensible [verified].
4. **The read-aloud test** (David A.) — read one paragraph aloud and ask whether it sounds like
   a person or a press release wearing a personality [verified].
5. **The one-sentence-worth-reading test** (David A.) — find one sentence in long copy so
   specific and well-made a reader would choose to read the next one [verified].
6. **The over-correction query** (Mary N.) — for each style-guide edit, ask whether the
   original was a deliberate quirk (the brand's signature) or a genuine error [verified].
7. **The slid-inconsistency audit** (Mary N.) — find the inconsistencies (spelling, comma
   philosophy, tone) that were let slide rather than caught [verified].
8. **The correct-or-query test** (Mary N.) — for every style rule, decide whether a violation
   would be corrected outright or merely queried, and make that judgment explicit [verified].
9. **The diaeresis test** (Mary N.) — name the one deliberate, slightly odd usage choice this
   brand would defend for thirty years; its absence means no real house style exists
   [verified].
10. **The ten-writers-five-years test** (Mary N.) — check whether the guide keeps the brand
    sounding like one voice across many hands and years, and where it fails to settle a real
    dispute [verified].
11. **The thirty-year test** (Tim D.) — ask honestly whether a hero line will still be running
    in thirty years or is built to fill a campaign cycle [verified].
12. **The timestamp-strip test** (Tim D.) — check for any trend, slang, or this-quarter
    reference baked into copy meant to be timeless [verified].
13. **The product-truth test** (Tim D.) — verify that any cleverness serves the product truth,
    not the writer's own display of wit [verified].
14. **The write-up test** (Tim D.) — rewrite copy assuming the reader is more intelligent and
    more skeptical than the brief assumed [verified].

[inferred] The wife test (David A., #1) and the write-up test (Tim D., #14) test the same
underlying discipline — respect for the reader's intelligence — from two directions: David A.'s
targets condescension in TONE, Tim D.'s targets condescension in AUDIENCE ASSUMPTION. Running
both surfaces cases either alone would miss.
