# Canonical tests — the concrete diagnostics this family runs

Each test is [verified] as a specific, repeatable prompt drawn from a persona file
(`check-brand-council/references/critics/`, dated 2026-08-20).

1. **The one-sentence-no-deck test** (George L.) — state the Big Idea in one sentence with no
   supporting slides; if it takes context to set up, there's no idea yet [verified].
2. **The cover-and-collide test** (George L.) — cover the visuals and read only the line, then
   cover the line and view only the image; if neither alone produces feeling, there is no
   collision, only wallpaper [verified].
3. **The knot-in-the-stomach test** (George L.) — ask whether the work makes anyone internally
   nervous; if it's safe enough that nobody is nervous, it's safe enough nobody will notice
   [verified].
4. **The original-version test** (George L.) — find the more dangerous version that existed
   before legal/committee filed it down, and ask whether it can come back [verified].
5. **The inventive-vs-expressive ratio** (Nick L.) — sort the work's creativity into what the
   brand DOES versus what it SAYS, and state the ratio explicitly [verified].
6. **The strip-the-styling test** (Nick L.) — remove the visual styling and tagline and ask
   whether anything distinctive remains in what the brand actually offers [verified].
7. **The fifty-surfaces test** (Nick L.) — scale a hero artifact to fifty surfaces, three
   regions, and a team not in the room, and name the system (or its absence) that makes that
   possible [verified].
8. **The generative-engine test** (Nick L.) — distinguish a real creative operating system
   (principles + components + decision rules) from a static style guide of frozen assets
   [verified].
9. **The cheap-alchemy scan** (Rory S.) — identify one small, nearly-free perceptual change
   (a name, ritual, frame, story) that would shift how the brand feels disproportionate to its
   cost [verified].
10. **The psycho-logic audit** (Rory S.) — find where the brand's reasoning is materially
    correct but ignores how people actually perceive, anticipate, or remember [verified].
11. **The spurious-quantification hunt** (Rory S.) — find where an easy-to-measure metric was
    allowed to overrule a meaningful, harder-to-measure quality [verified].
12. **The fat-tail test** (Rory S.) — argue the counterintuitive opposite of the work's central
    choice; if nothing in the brief "doesn't make sense," it's probably too sensible to be
    remarkable [verified].

[inferred] Test 5 (Nick L.'s inventive/expressive ratio) and test 9 (Rory S.'s cheap-alchemy
scan) both look for the SAME missing thing — a real, low-cost creative act embedded in what the
brand does rather than only in what it says — from adjacent angles; a work item failing both
usually has one root cause, not two.
