# Failure modes — what this family's critics catch

Named per critic, each [verified] against `check-brand-council/references/critics/`
(dated 2026-08-20). `make-critic` step 2's overlap check reads this file before drafting a new
advertising-creative-family lens.

| Failure mode | Symptom | Critic who catches it |
|---|---|---|
| Idea needing a deck | The concept requires three slides of setup before it lands; there's a mood, not an idea | George L. — "if you need three slides of context to set it up, there is no idea here" [verified] |
| Word/image non-collision | The line and the visual sit politely next to each other instead of being one thought | George L. — "you've handed me a nice picture and some separate nice words" [verified] |
| Committee-filed-down risk | The dangerous original version was sanded down by legal/CMO/focus group into something safe | George L. — "which line was the original, dangerous version" [verified] |
| Culture-reflecting instead of culture-moving | The work reflects existing culture rather than trying to shift the conversation | George L. — "reflecting is for mirrors" [verified] |
| Expressive lipstick on a generic product | Nearly all the creativity is in messaging/image, none in what the product or brand actually does | Nick L. — "95% expressive lipstick on a generic product" [verified] |
| Decoration mistaken for brand idea | No concrete behavior, feature, or service the brand could invent to express the idea more powerfully than communication alone | Nick L. — "is the brand idea here doing real work, or is it decoration" [verified] |
| No creative infrastructure | The work is a brilliant hero artifact with no system (platform, rules, reusable logic) that lets it scale to fifty surfaces | Nick L. — "if the answer is 'redo it by hand each time,' this has no infrastructure" [verified] |
| Style guide mistaken for creative engine | What's presented as a "system" is really a frozen set of finished assets, not a generative engine | Nick L. — "does this work define a generative engine... or just a frozen set of finished assets" [verified] |
| Alchemy walked past | A cheap, nearly-free perceptual reframe was available and ignored in favor of spending on material features | Rory S. — "if the work only adds material features, it's spending money where alchemy was free" [verified] |
| Psychologically tone-deaf logic | The brand's reasoning is materially correct but ignores how people actually perceive or remember the experience | Rory S. — "materially correct but psychologically tone-deaf" [verified] |
| Spurious quantification | A measurable-but-shallow metric overrules a meaningful-but-hard-to-measure quality | Rory S. — "chasing a metric that destroys the magic to make a chart look good" [verified] |
| No fat-tailed bet | Every choice is moderate and de-risked; no asymmetric, small-downside/large-upside idea survives | Rory S. — "the work has optimized away its only chance of an outsized win" [verified] |

[inferred] George L.'s "committee-filed-down risk" and Rory S.'s "no fat-tailed bet" name the
same organizational failure (risk-aversion sanding down a genuinely bold choice) from two
different lenses — one narrative/creative, one probabilistic/strategic — and both can legitimately
fire on the same piece of work without being redundant findings.
