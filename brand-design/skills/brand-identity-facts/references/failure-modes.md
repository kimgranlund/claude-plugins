# Failure modes — what this family's critics catch

Named per critic, each [verified] against `check-brand-council/references/critics/`
(dated 2026-08-20). `make-critic` step 2's overlap check reads this file before drafting a new
identity-family lens.

| Failure mode | Symptom | Critic who catches it |
|---|---|---|
| Category-swap identity | Three competitors' names could be swapped in and the work would still read true | Jessica W. — "you've described a category, not a brand" [verified] |
| Machine-generatable identity | An identity a model could produce in thirty seconds, with no human "wrongness" or signature decision | Jessica W. — "in the AI era, the generic is the failure state" [verified] |
| Skipped excavation | Typography/color chosen before the brand's own fears and beliefs were ever examined | Jessica W. — "you've decorated a personality you never bothered to know" [verified] |
| Optimized for inoffensiveness | No element exists that a focus group would flinch at | Jessica W. — "optimizing for inoffensiveness... is the same as optimizing for invisibility" [verified] |
| Broken three-level coherence | The system's semantic claim ("trust") contradicts its own syntactic execution (illegible mark, inconsistent weights/colors) | Massimo V. — "which level fails first — and why did you ship before fixing it" [verified] |
| No governing grid | No modular structure can be drawn that governs every layout; the identity is a collection of pretty pages that will drift apart | Massimo V. — "there is no system here" [verified] |
| Typeface indulgence | Five or six typefaces specified with no defensible reason each earns its seat | Massimo V. — "you have spent that budget on a single brand" [verified] |
| Costume, not identity | Strip the current trend/gradient/oversized type and nothing recognizable remains | Massimo V. — "you have designed a costume, not an identity" [verified] |
| Rented, not drawn, type | A proprietary typeface behavior never justified against renting a face a thousand other companies also use | Matt W. — "defend renting a face that a thousand other companies also rent" [verified] |
| Body-text blind spot | The presentation shows only glamour headlines; no proof the system holds at 2,000 words, a caption, or a 10px legal line | Matt W. — "editorial design lives in the body text" [verified] |
| Vibes-not-structure hierarchy | Type hierarchy is undefined as a rule; an editor would have to improvise when content doesn't fit the drawn levels | Matt W. — "if the answer is 'we'd improvise,' the system isn't finished" [verified] |
| Founder-dependent system | The identity only holds together in the founder's own hands, not when handed to a junior designer under deadline | Matt W. — "it's a performance," not an identity [verified] |
| Brittle single-lockup mark | The identity breaks the instant it leaves the brand guidelines — a favicon, a foreign script, a hostile background | Paula S. — "name the context where this one becomes unrecognizable or falls apart" [verified] |
| Sticker, not system | Recognition depends entirely on one fixed lockup placed just so, with no generative typographic/behavioral language behind it | Paula S. — "this isn't an identity, it's a sticker" [verified] |
| Sanded-safe identity | Every choice has been softened to be agreeable; nothing decisive or slightly dangerous remains | Paula S. — "a timid identity that offends no one is forgotten by everyone" [verified] |
| No editorial refusal | "Anything goes" — the system has no discipline about what it excludes | Paula S. — "an identity with no spine and no boundaries" [verified] |

[inferred] Massimo V.'s three-level coherence failure and Paula S.'s brittle-lockup failure are
often the same underlying defect seen at two different test points — a system with no real grid
(Massimo V.'s test) is also the system most likely to shatter the moment it's stress-tested at
scale (Paula S.'s test) — so a full identity review benefits from running both rather than
treating either finding as redundant with the other.
