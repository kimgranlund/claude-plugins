# B3 — knowledge skill holding documentation-writing rules

**Name:** `doc-authoring-standards`

**Reasoning:** Noun-phrase `-standards` suffix marks it as a knowledge skill (rules to consult), matching the established `*-authoring-standards` family (skill-, agent-, hook-authoring-standards) — a verb-first name would wrongly signal a procedural/command skill. `doc` names the artifact governed, keeping the name short, routable, and stutter-free.
