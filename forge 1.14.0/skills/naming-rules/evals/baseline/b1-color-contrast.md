# Proposed skill name

**`contrast-verify`**

Reasoning: it names the checked property (contrast) plus the action (verify), matching the workspace's established `*-verify` family for pass/fail verification skills (focus-verify, i18n-verify, color-verify), and stays disjoint from any plugin-name prefix — no `color-` or `ui-` stutter, no reserved words (`claude`/`anthropic`), plain kebab-case. WCAG is the criterion it verifies against, so it belongs in the description, not the name — naming the standard would date the skill (WCAG 3 / APCA) without adding routing signal.
